# v3.0.4

## 新增与完善

- Web 后台支持 QQ 自定义菜单和四种场景的指令面板管理，包含预览、覆盖确认及群／用户关联对象管理。
- 群宠战绩追踪独立为插件，支持 7 天有效期、每群 3 位玩家、活跃度轮询、权限检查、跨群共享查询及成功推送计数；图片同条附带宠物提醒文案。
- B站直播通知拆分为独立插件，支持申领授权、每群／用户一个房间、首次直播补发、开播／下播图文通知及推送计数。
- 完善玩家战绩、对局结算、角色多武器选择、技能优先学习顺序、角色排行、装备合成树与使用率展示。
- 完善活动与兑换码文章去重、首次发现／到期提醒及最新补丁摘要与正文配图缓存。

## 运行保障

- 业务数据库操作统一为 Ktorm DSL，保留独立建表与迁移脚本。
- 优化图片缓存、预取和请求合并，完善 Linux 韩语及数字排版。
- 业务 HTTP 显式使用 JDK 引擎规避 CIO 连接许可异常，取消请求不再误重试；QQ SDK 传输保持独立。
- 新增心跳与 SMTP 故障告警，完善 QQ 令牌刷新、重复消息防护及 Web 运行状态展示。

## 许可与分发

- 自有代码采用 **GNU AGPL-3.0-or-later**，保留第三方依赖、字体及前端资源的原始许可。
- 提供 `qgbot-3.0.4.zip`、`onebot-3.0.4.zip`、`plugins-3.0.4.zip` 与 `SHA256SUMS`。
- 主程序包包含对应 JAR、独立插件、功能说明和许可证；插件包供现有宿主选择性更新。
- QQ 菜单管理及 core 内部改动需要更新主程序并重启，不能仅靠热更新业务插件获得。群宠、直播及 QQ 菜单能力受 QQ 平台权限限制。
