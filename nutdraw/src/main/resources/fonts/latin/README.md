# Bundled Latin font

Noto Sans variable font, distributed under SIL Open Font License 1.1 (`OFL.txt`).

Source: https://github.com/google/fonts/tree/main/ofl/notosans

Original file: `NotoSans[wdth,wght].ttf`; stored as `NotoSans-wdth-wght.ttf` without modifying the font.

Printable ASCII uses the regular (400) / bold (700) instances at the requested font size. This keeps numeric column measurements stable on Windows and Linux even when no configured CJK/Arial font is installed. Other scripts continue to use the existing fallback policy.
