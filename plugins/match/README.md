# 对局详情插件

已读取 `design-taste-frontend`，仅采用适用于数据页面的层级、间距、颜色和固定字号原则，不采用营销页的大图、动画或装饰布局。

## 页面设计

- 白色队伍面板、浅灰外画布、金色焦点提示，圆角统一为 8px。
- 1440px 宽固定图片：对局信息 → 焦点/全场摘要 → 两列队伍面板。真实查询不显示左下角结算说明及其占位空白。
- 按名次排列队伍，8 支三人队伍一张图展示；不是只展示查询者所在队伍。
- 每位玩家展示头像、昵称、角色、生存时间、KDA、RP、对玩家伤害、承受伤害、五件最终装备、武器、天赋与战术技能、治疗、视野与荣誉值。
- 同列统一 box 与数字对齐；伤害字号固定为 22px，昵称为 18px。长昵称省略，不自动缩小字号。
- 焦点玩家及其队伍轻度突出。最高伤害仅作为数值摘要，不使用未经证明的 MVP/评分标签。
- 缺失数值显示“暂无”，缺失装备保留槽位；不把未知数据转为 0。
- 预览样例明确标注“非实时战绩”。昵称、游戏编号与数值均不能作为真实对局信息使用。

设计参数：`DESIGN_VARIANCE=3`、`MOTION_INTENSITY=0`、`VISUAL_DENSITY=7`。这是 NutDraw/Skia 图片模板，不是浏览器或官方 UI 组件库实现。

## 文件与预览

- `MatchDetailData`：独立页面模型，避免直接绑定上游大 DTO。
- `MatchDetailTemplate`：实际可渲染模板，而非静态概念图。
- `MatchDetailDesignTest`：生成 `build/previews/match-detail-design.png`，检查固定字号、五/六位伤害数值对齐、韩文昵称、长昵称与空状态。
- `MatchPlugin`：注册真实 `查询对局` 指令；不会把设计样例图作为真实查询结果返回。

验证：`./gradlew :plugins:match:test :plugins:match:jar`。预览只读取已有本地头像与装备资源，不请求 DAK.GG。

## 查询方式

`/查询对局 <gameId> [nickname seasonId]`，也可点击玩家查询中的最近三局回调按钮直接查询。昵称与赛季 ID 必须同时提供；不包含玩家时显示全场视角。
