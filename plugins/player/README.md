# 玩家查询插件

- QQ 官方机器人与 OneBot 均返回原始战绩图片（离线图片／Base64），不再附带查询对局或兑换码按钮，也不再将玩家图片转换为 Markdown 公网链接。
- 仅在兑换码首次入库的当天附带 `发现新的兑换码:...` 字符串，在有效期最后一天附带 `即将过期的兑换码:...` 字符串。按自然日判断，不使用过去 24 小时或提前一天的提醒。
- 未生效、已过期、空白兑换码不展示；兑换码去重，同时新发现且今日到期时只显示到期提醒。
- 玩家查询不再注册按钮回调监听器。玩家别名和 `/test` 的按钮不受影响；仍可手动使用 `/查询对局` 和 `/兑换码`。

发布新版本后需重新查询玩家：已发出的旧消息内容不会变更。
