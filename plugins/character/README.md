# 角色数据插件

## 角色详情（1.2.3）

白粉战术报告样式：白色画布、无填充分区和深玫瑰粉强调；移除卡片与条纹底色，保留装备品质图及必要的图标衬底；角色与武器概览保留大字号，关键胜率使用深玫瑰粉强调，RP 正负分别显示绿／红。技能前两套优先升满顺序以对应图标、键位与箭头显示，并与战术技能左右并排；潜能核心与副潜能分栏，成装使用更大的品质背景图标与下方名称。分区使用统一细分隔线，不引入前端框架或动效。

保持 1000px 画布和原有字号，所有数据、筛选及命令行为不变；空数据及仅装备视图分别处理。详情缓存升级 v11，仅装备缓存升级 v4，避免继续使用旧版布局图片。

- `/查询角色 娜汀 无暇`：省略模式直接指定段位；默认排位、灭钻。也兼容 `/查询角色 娜汀 排位 无暇`。
- 当前筛选条件有多个武器时，QQ 返回 Markdown 武器选择菜单。按钮将保留段位、模式和武器的查询命令填入输入框，不直接执行，需用户确认发送。
- `/查询角色 娜汀 无暇 弓`：直接指定武器名称或 ID；OneBot 返回可复制的武器查询指令。
- `/查询角色 娜汀 钴协议 弓`：钴协议不附加排位段位过滤。
- 技能学习按使用次数排序，仅展示前两套优先升满顺序（如 `T → Q → E → W`），不显示逐级加点；图片缓存区分武器、模式和段位。
- 选择菜单不预热详情图片，选定后再下载对应武器的资源。

- `/角色数据 [段位]` 展示角色元数据中的全部可用角色与武器组合，同时保留统计接口实际返回的组合，不按 S／A／B／C／D 评级过滤。
- 有统计时显示上游真实评级、胜率与平均伤害；没有统计或场次为零时保留角色／武器图片并显示“暂无数据”，不伪造 D 级或 0% 胜率。
- 右上角为当前排序序号；有统计的组合按评分、场次排序，暂无数据的组合置于末尾。字号及网格布局保持不变。
- 图片缓存使用 `v3` 独立路径，有效期 15 分钟；生成新图时刷新角色元数据和统计快照，再预热图片资源，避免长期复用开版本初期的全 D 旧图。
- 共享核心的数据结构保持不变，可单独热更新本插件，无需重启主程序。
